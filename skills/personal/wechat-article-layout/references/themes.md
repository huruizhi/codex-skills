# Theme Selection

Use themes by article intent, not personal preference.

| Theme | Chinese Label | Best For |
|---|---|---|
| `tech-blue` | 科技蓝 | AI、云计算、开发者工具、技术商业分析 |
| `clean-news` | 清爽新闻 | 快讯、资讯汇总、客观新闻稿 |
| `deep-analysis` | 深度分析 | 长文、行业判断、商业分析、趋势复盘 |
| `product-review` | 产品评测 | 工具推荐、产品体验、App/开发者工具介绍 |
| `ai-dark` | AI 暗色 | 大模型、Agent、前沿技术、发布会解读 |
| `business-gold` | 商业金 | 融资、财报、资本、云厂商、商业模式分析 |
| `startup-orange` | 创业橙 | Product Hunt、创业产品、增长、工具新品 |
| `knowledge-green` | 知识绿 | 教程、方法论、知识科普、工作流拆解 |
| `minimal-gray` | 极简灰 | 短评、工程笔记、低装饰技术文章 |
| `magazine-red` | 杂志红 | 评论、批判、观点稿、风险和安全话题 |

## Defaults

- Use `tech-blue` for general technology articles.
- Use `business-gold` for investment, finance, cloud contracts, and capital-market analysis.
- Use `product-review` for tool recommendations.
- Use `knowledge-green` for how-to or framework pieces.
- Use `clean-news` for daily briefings and neutral reporting.
- Use `magazine-red` only when the article has a strong warning, critique, or safety angle.
- Use `ai-dark` selectively; it is visually stronger and should not be the default for every AI article.
